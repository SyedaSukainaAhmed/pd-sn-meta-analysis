# pd-sn-meta-analysis
Reproducible R pipeline for a Parkinson's disease substantia nigra transcriptome meta-analysis: 5 public Affymetrix cohorts, limma + robust rank aggregation, dopaminergic-score adjustment, negative controls, RNA-seq check.
# Parkinson's disease substantia nigra transcriptome meta-analysis

Code, results tables and figures for the preprint "Reproducible substantia nigra changes in Parkinson's disease track dopaminergic marker expression across samples" (Ahmed SS, 2026; bioRxiv link to be added).

Data: public GEO cohorts GSE7621, GSE20163, GSE20292, GSE49036, GSE8397 (microarray) and GSE136666 (RNA-seq). Raw files are not included; scripts download them from GEO.

Software: R 4.6.2. Full package versions are in sessionInfo.txt.
